## ⚙️ Как это работает

Бот выполняет циклическую последовательность действий для автоматического сбора ценных предметов в игре.

### 📸 1. Захват изображения игры

Первый шаг — получение текущего состояния игрового экрана.

**Решение:** Захват скриншота игры и передача его в следующие этапы обработки.

### 🔍 2. Поиск ценных предметов на изображении

Необходимо обнаружить ценные предметы (монеты, ключи, звёзды) на скриншоте и получить их координаты.

**Технология:** Алгоритмы **Template Matching** от `OpenCV` идеально подходят для этой задачи.

Они используются для поиска и определения местоположения **шаблонного изображения** (например, монеты) в большем изображении (например, игровом экране). Алгоритм просто "скользит" шаблоном по входному изображению (как при 2D-свёртке) и сравнивает шаблон с участком изображения под ним. В OpenCV реализовано несколько методов сравнения. (Подробнее в [документации](https://docs.opencv.org/4.x/d4/dc6/tutorial_py_template_matching.html)). Мы используем метод: `cv2.matchTemplate(...)`

### 🖱️ 3. Сбор предметов путём клика

После получения координат предмета можно выполнить клик по нему.

**Решение:** Функция `.click(x, y)` из библиотеки `pyautogui` отлично справляется с этой задачей. Она кликает на экране по координатам x и y, где находится наш ценный предмет.
Подробнее: [документация pyautogui](https://pyautogui.readthedocs.io/en/latest/mouse.html#mouse-clicks).
